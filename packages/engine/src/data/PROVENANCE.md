# Data provenance

Source: the upstream engine's `src/data/**` at revision
`e66896a0fa83b7336baaa5614d9fb7c8a7d61e88`.

The catalog is approximately 66,000 lines of static TypeScript. It is carried
under the source tree's AGPL arrangement over Digital Extremes-owned game
facts; the underlying game names, statistics, and assets remain the property
of Digital Extremes and are used under community fan-site convention.

Refresh this catalog only through a curated pull for each Warframe major patch.
See `docs/agent/upstream-sync.md` for the separately maintained process.
