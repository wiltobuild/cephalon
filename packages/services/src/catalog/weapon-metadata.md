# Weapon metadata provenance

`weapon-metadata.json` projects only name, native regular polarities, and weapon type from WFCD warframe-items Primary, Secondary, Melee, and Arch-Gun JSON files (retrieved September 10, 2026). Source: https://github.com/WFCD/warframe-items/tree/master/data/json . Game content belongs to Digital Extremes.

This supports native-polarity Forma accounting and category compatibility; it does not replace engine weapon statistics. Missing native records use an empty-slot baseline. Capacity plans currently use rank-30 doubled capacity (60); they do not claim rank-40 or stance bonuses. Guide layouts that still cannot fit at fully matching polarity remain flagged rather than lowering authored ranks.
