## Changing the update

Edit `apps/web/src/content/overview-campaign.ts`: current title/artwork/source, featured name/artwork/buildHref/description, and upcoming title/artwork/source/release date. Add the replacement official artwork here and record its provenance. The overview uses the configured featured name, not a hardcoded Warframe title.

DE announced September 23, 2026 for Iceblade of Narin but no exact launch hour on the source page as checked September 8. The countdown intentionally shows days to the release date, not a claimed launch time. The entire Coming Soon card disappears at the start of September 23 Eastern time (`2026-09-23T00:00:00-04:00`), including in an already-open tab. It does not automatically claim the update has launched or switch the current campaign. Update the featured Warframe and active campaign once the next release is confirmed.
