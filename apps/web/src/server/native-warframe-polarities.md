# Native polarity baseline

`native-warframe-polarities.json` is a projection of `name`, `polarities`, and `aura` from https://github.com/WFCD/warframe-items/blob/master/data/json/Warframes.json, retrieved 2026-09-09. It is used to count the minimum polarity changes needed for fully specified guide layouts. Regular slots can be rearranged. Aura and Exilus are counted separately. Incomplete guide layouts retain a labeled guide estimate rather than inferring unknown polarities. These counts describe the approved guide, not installed Forma on a player's account.
